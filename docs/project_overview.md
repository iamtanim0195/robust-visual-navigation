# Research Project Environment Specification

## System Information
- **OS**: Ubuntu 24.04.4 LTS (Noble Numbat)
- **ROS 2 Distribution**: ROS 2 Kilted Kaiju (`kilted`)
- **Simulation Engine**: Gazebo Sim 9.5.0 (Harmonic)
- **Middleware Integration**: `ros_gz_bridge` / `ros_gz_sim`
- **Python Version**: 3.12.3
- **Build System**: `colcon`

## Hardware Target
- **Compute**: Host PC / Laptop
- **Microcontrollers**: ESP32-CAM (Vision Streaming), ESP32-S3 (Real-time Control, IMU, Encoders)
- **Sensors**: MPU6050 IMU, 25GA370 Quadrature Encoders, RGB Camera
- **Kinematics**: Differential Drive Mobile Robot
